# Enfolded landing page

Public introduction to [Enfolded](https://github.com/mark-weeks/hello-nested-worlds-adventure), the open-source nested-scale world.

GitHub Pages publishes [`index.html`](index.html) from this repository. The page is static HTML and CSS: no theme, no JavaScript, no trackers, and no external fonts. [`_config.yml`](_config.yml) holds the site title and description. This README is excluded from the site build.

The hosted world is not deployed. Claims on the page come from the Enfolded README and `docs/`.
